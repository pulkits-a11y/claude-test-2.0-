# Endless Gallery — build notes

How the scene is built, why it's built that way, and how to rebuild it. Status as of the first full draft.

## Rebuilding the project

From `endless-gallery/.tesseract-work/`:

```bash
python3 timeline.py lamp_timeline.json
```

```bash
python3 gobo_render.py lamp_timeline.json /tmp/gobo_frames && ffmpeg -framerate 30 -i /tmp/gobo_frames/gobo_%03d.png -c:v libx264 -crf 6 -pix_fmt yuv420p -g 1 ../assets/generated/gobo.mp4
```

```bash
bash make_project.sh ../EndlessGallery.tsrct 1920 1080
```

`make_project.sh` creates the Tesseract project, packages the models, the light-mask video and the beam texture, then applies the actions generated by `build_gallery.py`. A full rebuild takes about 10 seconds.

## Why it's built this way

This cloud machine renders on CPU only (no GPU), so every design choice is about getting a premium look at an affordable render cost.

| Problem | What we measured | Solution |
|---|---|---|
| Path tracer (true haze, reflections) | 44 s for **one box** at draft quality; denoiser download blocked | Raster renderer, with beams and haze built as materials |
| ~1,100 full-detail shoes | 90 s per frame | Three detail tiers by row (hero row full, rows 1–5 medium, 6+ far). A row never changes tier, so nothing can pop. **21 s per frame** |
| One real spotlight per lamp | +4 s per light, +13 s per shadowed light; 40 lights = 6 min per frame | **One projector light** high above the hall with an animated mask (gobo): one soft disc per lamp. Costs about the same as no lights |
| Lamps catching, flickering, dying | — | Animate the discs in the mask video (`gobo_render.py`), driven by a seeded per-lamp timeline (`timeline.py`) |
| Visible beams | Raster draws no volumetric haze | Faint translucent cones **lit by the projector**, so each beam follows its lamp automatically, grain included. Fade from lamp to shoe via `beam_falloff.png` |
| Anti-aliasing | 16 samples = 219 s per frame | Render at 4K with 1 sample (42 s), downscale to 1080p |

## Compulsory effects: where each one lives

- **Noise inside light:** fine grain plus slow mottling in the projector mask, re-seeded every frame. It shows up inside every pool, on the pedestal tops and inside every beam.
- **Turbulent Displace:**
  - Built in: while a lamp catches or dies, its disc in the mask jitters and its edge wobbles with fresh fractal noise each frame, so the pool and beam physically shudder.
  - Still to add: a full-frame custom-shader Turbulent Displace at a very low constant level on the haze.
- **Displacement map:** still to add. It will be a custom-shader layer using **Grunge 353** (missing; please add it to the Drive folder) for 3-frame jolts at **f20–22** and **f50–52** (the fastest camera frames) and a slow crawl on the haze in Phase 4.
