# GTA 9/11 Cover Reel: build notes

Built in Tesseract (CLI 0.8.0) as one editable project, `GTA911_CoverReel.tsrct`, with a 1920 × 1080 main composition at 30 fps.
The project is generated by `build/make.py`, which runs `build/reel.py`, `build/lib.py`, `build/prep.py` and the WGSL shaders in `build/shaders/`. Rerunning it rebuilds the project from `source/`.
