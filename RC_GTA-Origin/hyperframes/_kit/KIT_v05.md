# KIT_v05: global style system + motion-graphics kit (REVISION_v05 G1-G8, doc section 2)

Read this first for v05. It overrides v02-v04 where they conflict (REVISION_v05 X); the other KIT_*.md files stay valid
for everything not named here. Sizes are @1080 (the doc's @720 px x 1.5). Every helper is deterministic (seeded, no
timers), eased (cuts are 0.5-frame step tweens between two frames: frame k shows the new state, k-1 the old one) and
identical every time it is called with the same arguments. `L(n)` = n / 30 below; `k` = the frame of `at`.

Proof: `hyperframes/_demo-v05/` (built by `tools/gen_demo.cjs` from this kit, the way a beat uses it): `review/snap/`
(`f<frame>_<what>.png`), `review/sheet_A..K.jpg`, `review/lockups.txt`, `review/check.json` (`check`: 0 errors).
Rebuild: `cd hyperframes/_demo-v05 && rm -rf assets/kit && cp -r ../_kit assets/kit && node tools/gen_demo.cjs && bash tools/snap.sh`.

Nothing to add to a beat's `<head>`: the new CSS lives in base.css / type.css / motifs.css and `RCK.fx` in motifs.js
(all beats already load the four kit CSS + JS files). Re-sync with `python3 tools/sync_kit.py`.

## 1. Fonts and palette (base.css)

|---|---|---|---|

| Tier B key word | `--serif` (italic) | "Coolvetica Italic" | Coolvetica-Italic.otf (unchanged) |

Every weight in a face's range maps to its one file and `font-synthesis: none` stays on (no faux bold / oblique).
Metrics measured in the render Chrome (`RCK.type.fontWidth(font, text, px)`, `fontExtent`): baseline in a line box of
height = size at 0.864 em (Inter), 0.867 (Coolvetica), 0.915 (Playfair), 0.846 (Arimo); cap height 0.735 / 0.672 /
0.719 / 0.704; Playfair digits 0.735.

Palette (G1): `--accent` #FF2E7E (entry flash, pills, highlighter, pixel glitch, the pin), `--annot` #FFD23F (hand-drawn
arrows / circles / underlines only), `--danger` #E3262B (stamp, red grid cells, the "cop" strike, siren red),
`--siren-blue-v5` #2E6BFF, `--dull-grey` #8A8A8A, `--text-drop` = 0 6px 18px rgba(0,0,0,.45) (all caption text),
`--card-bg` #0E0E10 (G8 dark cards), `--paper` #F2EEE6, textures `--grain`, `--paper-grain`, `--paper-fibre` (static
seeded SVG noise).

## 2. Captions v05: in place (`T.lockupPlan`, `T.lockups`, `T.lockupsWire`, same calls as v03)

**What a re-sync changes for an existing beat (no spec rewrite needed):**
* `T.lockupsWire(tl)` now gives EVERY word the doc 2.3 entry (v03: plain words just appeared, starred words popped).
* Lockup HTML generated by v03 (no `data-rc-v="5"`) is re-laid out at wire time with the v05 tiers (same rows, words and
  frames): setup rows Inter SemiBold 54 px, key rows Coolvetica Italic 190, the box re-centred on `--rc-y`. So a beat
  gets the v05 look by syncing the kit; re-running `T.lockups(...)` (recommended) also gives the v05 line breaks and
  inline sizes in the HTML. A v03 starred word (`rc-lw--pop`) keeps the key-word colour timing.
* Text shadow: `--text-drop` (v03: the white ref 3 glow); colour flash #FF2E7E on every word.
* The block drifts 100 -> 104% over its life; exits stay hard cuts unless `exit: 'blur'`.
* `.rc-card` is now #0E0E10 + grain + the v04 scanlines (no charcoal lift); add the footage loop with `RCK.fx.darkCardHTML`.

**Tiers (G2):** A setup = Inter SemiBold 54 px (51-57; `setupSize`; solo lines on a card `card: true` = 57), sentence case,
tracking 0 / B key `[ ]` = Coolvetica Italic 190 px (165-210; `keySize`; 3.5 x setup) / C hero `[[ ]]` = 450 px by
default (`hero` / `heroSize`, 330-600, may run off frame: never shrunk), Coolvetica Italic for words, Playfair Display
Black for numbers and dates (auto: digits, or "NOV 1997"; force with `heroFont: 'playfair' | 'coolvetica'`) / Q quote
(`tier: 'quote'`) = Playfair Display Italic 105 px, its key 135 px / the "dull." gag (`#` on the key) = Arimo 180 px
#8A8A8A, no shadow, no entry.

**Layout (G3):** setup line directly above the key word, left-aligned to it ("small over big"); words after the key
below its right edge; the block centred in frame on `--rc-y` (540; `y` option) as in v03; descender guard kept (a row's
highest glyph clears the previous row's deepest glyph by 8 px: "[[Why]] does" puts "does" 96 px lower, below the y).

**Spec markers** (one string per lockup; a spec may also be an object `{ s, ...options for that lockup }`):

| Marker | Meaning |
|---|---|
| `[word]` / `[two words]` | tier B key (one group per lockup) |
| `[[word]]` | tier C hero (instead of a key group). Size: `{ s: '[[Why]] does', hero: 450 }` |
| `word*` / `]*` | emphasis: the key-word colour timing (pink to f4, white by f8) on a setup word (v03 stars) |
| `word!` / `]!` | plain: no entry, hard cut on its frame |
| `word~` / `]~` | siren entry: #E3262B / #2E6BFF every 2f for 8f, then white (with the standard scale / blur entry) |
| `word#` / `]#` | the "dull." gag: no entry, Arimo grey 180 px (on the key group) |
| `word^` / `]^` | stays pink (B17 "caught.") |
| `\|` | forced line break among setup words |

```js
// Node (paste the HTML), one timed element per lockup:
const p = T.lockupPlan(w, [{ s: '[[Why]] does', hero: 450 }, 'every [GTA,]'], { from: 0 });
T.lockups(p, null, { idPrefix: 'b01-lk', z: 40, track: 20 });   // + T.lockupReport(p), T.lockupCues(p)
T.lockups(w, ['Because back in [[1995,]]'], { from: 0, hero: 480 })               // Playfair Black (a number)
T.lockups(w, [{ s: '[[broke.]]', hero: 390, y: 820 }, 'And that [bug] saved it.'], { from: 9 })
T.lockups(w, ["it's [dull.]#"], { from: 4 })                                       // no entry, Arimo grey 180
T.lockups(w, [{ s: 'from the [cops?]~', keySize: 240 }], { from: 10 })             // siren entry
T.lockups(w, [{ s: '[“awful…] too sim-y.”', tier: 'quote' }], { from: 11, loose: true })
T.lockups(w, ['Until finally,'], { from: 0, card: true, exit: 'blur' })            // 57 px solo, 3f blur-out exit
// beat script, once after the markup:
T.lockupsWire(tl);
T.glowFlicker(tl, '#b02-lk-1 .rc-lk__row--num .rc-lw', W[3].comp_t);   // v04 glow flicker layered on the entry
```
`T.lockupCues(plan, offsetF)` -> `{ word_pops: [...], key_words: [...] }` (entry frames for cues.json v05: key / hero /
starred -> key_words, other words -> word_pops, "dull." neither).

**Entry timings (G4)**, word frame k = round(comp_t x 30) (never earlier than the voice; the first visible frame is
k+1, 0.5-1.5 f after the onset). Ease = cubic-bezier(0.2, 0.8, 0.2, 1) = `RCK.ease.trailer` (0.25 -> 0.767,
0.5 -> 0.946, 0.75 -> 0.991):

| frame | opacity | scale | blur | colour (setup) | colour (key / hero / `*`) | `~` siren |
|---|---|---|---|---|---|---|
| k | 0 | 112% | 9 px | #FF2E7E | #FF2E7E | #E3262B |
| k+1 | 0.95 | 102.8% | 2.1 px | pink | pink | red |
| k+2 | 1 | 100.6% | 0.5 px | pink (fade starts) | pink | #2E6BFF |
| k+3 | 1 | 100.1% | 0.1 px | fading (sine.inOut) | pink | blue |
| k+4 | 1 | 100% | 0 (filter removed from k+5) | fading | pink (fade starts) | red |
| k+6 | 1 | 100% | | white | fading | blue |
| k+8 | | | | | white | white |

Block: `.rc-lk__box` scale 100 -> 104% from the clip's first to its last frame (sine.inOut), origin = the ink centre.
Exit `exit: 'blur'` (or `data-rc-exit="blur"`): the last 3 frames blur 0 -> 12 px + opacity 1 -> 0 (power2.in), gone on
the clip end. `T.lockupsWire(tl, scope, { drift: false })` turns the drift off; `{ entry: false }` = v03 hard cuts.
Layering: `T.glowFlicker`, `T.sirenFlicker` and `RCK.fx.rgbSplit` on a lockup word drive its inner `.rc-lw__fx` span, so
they sit on top of the entry (which drives the word span).

## 4. Render cost

Blur filters run only during entries (a word's blur is removed from k+5), the RGB split only on its frames, the
glitch blocks are transforms on a fixed pool of 16 divs; textures are static. Heavy: media-treatment blur (multipass)
on the card-insert / dark-card backgrounds (one full-frame layer each) and during flips / whip-zooms only.

## 5. Not done / limits

* [DEPTH] masking is a lane job (G7): cut the subject out (`remove-background`) and stack plate -> lockup -> cut-out;
  a lockup is one element, so a hero behind the subject with setup words in front = two lockup calls.
* The RGB split on footage during a 'cut' glitch is not applied to the footage (rule 11): the blocks carry the split;
  use `fx.rgbGrading` on a frozen still for "broke.".
* The tear-off calendar and the error window are generic recreations (no OS marks); the UK outline is hand-traced
  (about 100 points) and reads at tag size, not as a map.
